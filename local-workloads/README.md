# Imagine Together — private grants beta

Open https://imagine-together-dharmic-beta.netlify.app . Invited learners can capture grant sources, keep unfinished thoughts, invite one collaborator, ask Bonsai for suggestions, and approve a shared brief with explicit source-linked reviews.

Read [the live beta handoff](beta-runtime/README.md) for access, verified behavior, data boundaries and recovery. This is a presenter-operated trial on Jai's GB10, connected through Netlify. The temporary backend connection and local power dependence must be replaced before an ongoing class. The hosted edition currently supports sources and reviewed briefs; the licensed visual canvas remains in the preserved local edition.
