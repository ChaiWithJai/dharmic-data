# Imagine Together

Capture unfinished thoughts. Help grant writers and their collaborators imagine together, preserve sources, and write canonical documentation they can explicitly agree to.

This branch is a separate collaboration edition of Jai's accepted personal Dharmic Swipe Studio. [The preserved personal version](https://github.com/ChaiWithJai/dharmic-data/tree/8a9b0a9b14eb6f2466d4e94cee51a910dfd9092c/local-workloads) remains independently runnable. Its source manifest describes that baseline, not this derivative.

Start with the [local installation and workflow](team-studio/README.md). The collaboration backend is `team-studio`, paired with `studio-web`. The historical `studio` backend is retained for lineage; use the preserved branch for the personal app.

The local pilot includes named accounts, workspace roles, source cards, a real canvas, optional Bonsai suggestions, explicit review of exact brief revisions, a decision ledger, and Markdown exports with cited source snapshots. Changes invalidate stale approvals. Model suggestions never imply agreement. MLflow records execution separately from human feedback.

[Learn with Jai on Maven](https://maven.com/a-plus). Workshop links are optional; writing, exporting and collaborating are not gated on enrollment.
